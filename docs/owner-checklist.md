# ของที่รอเจ้าของงานอยู่ตอนนี้

หน้าเดียว · รายละเอียดเต็มอยู่ใน [`provisioning-runbook.md`](provisioning-runbook.md)

```bash
./scripts/prepare-provisioning.sh              # ตรวจว่าอะไรยังขาด ไม่เปลี่ยนอะไร
./scripts/prepare-provisioning.sh ~/tokens.txt # + สร้างโทเคนลงไฟล์นอกรีโป mode 600
```

สคริปต์นี้พิมพ์คำสั่งที่ต้องรันต่อให้เอง ตามสถานะจริงในตอนนั้น · **ไม่เปลี่ยนอะไรเลยสักอย่าง**

---

## 1 · แถว workspace ของ Multi-Agent Lab

runner สร้าง workspace เองไม่ได้ · ไม่มี tool ไหนสร้างได้เลย

คำสั่งได้จากสคริปต์ข้างบน — มันจะใส่เฉพาะใบที่ยังขาด ไม่ซ้ำของที่มีแล้ว

**ยืนยัน:** รันสคริปต์ซ้ำ ข้อ 1 ต้องขึ้นว่า *ครบแล้ว*

## 2 · โทเคนแยกชื่อ

**หนึ่งใบผูกได้ชื่อเดียว และชื่อจากโทเคนทับ `X-Client-Name` เสมอ** — ทางนี้เท่านั้นที่ปลอมชื่อกันไม่ได้

```bash
$EDITOR ~/tokens.txt      # วางค่าเดิมเพิ่ม บรรทัดละใบ รูป token=ชื่อ
paste -sd, - < ~/tokens.txt | npx wrangler secret put MCP_AUTH_TOKENS
./scripts/verify-tokens.sh ~/tokens.txt
```

ป้อนผ่าน stdin ไม่ต้องพิมพ์ค่าเอง และไม่เข้า shell history

> ⚠️ **`wrangler secret put` เขียนทับทั้งก้อน ย้อนไม่ได้ และอ่านค่าเดิมกลับไม่ได้**
> 9 ก.ย. เคยตกไปหนึ่งใบ ทุก client ได้ `401` พร้อมกันยี่สิบนาที
> **ถ้าไม่มีสำเนาค่าเดิมอยู่ในมือ อย่าเดา** — ออกใหม่ทั้งชุดแล้วแจ้งทุกทีมแทน

`verify-tokens.sh` ยิงทุกใบแล้วเทียบชื่อที่ได้กลับ · **ไม่พิมพ์โทเคนออกมาเลย** · ปฏิเสธถ้าไฟล์อยู่ในรีโป

## 3 · `tenant_id` ของ lab — ตัดสิน ไม่ใช่รันคำสั่ง

**ระบบนี้ไม่มีแนวคิด tenant อยู่เลยสักที่** — ช่องนี้เป็นของสัญญาฝั่ง `agent-platform`

**ห้ามเอา `ws-001` ไปใส่แทน** · `workspace` ข้ามได้ด้วยรหัสอย่างเดียว (`test/workspace-isolation.test.ts` พิสูจน์แล้ว) ส่วน `tenant` เป็นขอบเขตแข็ง — เอามาใส่แทนกันคือประกาศว่าสองแกนนี้เป็นแกนเดียว

## 4 · สร้าง vault ของจริง — ยังไม่เคยทำสักครั้ง

```bash
MCP_TOKEN=... node scripts/export-vault.mjs ~/collab-vault
```

อ่านอย่างเดียว ไม่เรียก tool ฝั่งเขียนสักตัว · ปฏิเสธปลายทางที่อยู่ในรีโป

---

## สองข้อที่ระบบ **ไม่** กันให้ ต้องกันเอง

**ไม่ส่งพารามิเตอร์ `workspace` = เขียนลง `ws-001`** · ไม่ error ไม่เตือน ดูสำเร็จปกติ

**ลบอะไรไม่ได้เลย** · ข้อความลบไม่ได้ ไม่มี tool ลบ และจะไม่มี — ห้ามโพสต์ความลับ · PII · รายชื่อลูกค้า · เนื้อเอกสาร/งบ
